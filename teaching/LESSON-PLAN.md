# K122 分步教學計畫（第 1–10 章）

每一步都照這個循環：**旁白稿 → 字幕影片 → 使用者操作 → 回報 → 判讀**。

## 本書的特殊做法

書上輪流使用 Copilot、ChatGPT、Gemini、Blackbox AI、Tabnine、Cursor。本課程**預設全部用 Claude Code 扮演這些工具的角色**，因為你已經有 Max 訂閱，不必另外註冊付費。

- 書的重點是「每個開發階段怎麼和 AI 協作」，不是工具本身的按鈕，所以換成 Claude Code 也能練到同樣的流程。
- 書上「比較多個工具」的段落（4.2、7.1、8.4），改成兩種做法擇一：
  1. 同一個提示詞用不同模型各跑一次（`/model` 切換 Opus／Sonnet／Haiku）
  2. 你手邊有的其他工具（claude.ai 網頁、Gemini 網頁、Codex），各貼一次
- 第 10 章 Cursor：有裝 Cursor 就照書用；沒有就用 Claude Code 做同一個遊戲。

**練習資料夾**：

- 第 2 章：`%USERPROFILE%\workspace\k122-ch02-practice`
- **第 3～8 章共用同一個專案**：`%USERPROFILE%\workspace\k122-ham-practice`。從空資料夾開始，一章一章把 HAM 測驗 app 做出來
- 第 9 章：`%USERPROFILE%\workspace\k122-ch09-practice`
- 第 10 章：`%USERPROFILE%\workspace\k122-ch10-practice`

**對照資料**：

- 書附完成版：`code/HAM-Radio-Practice-Web`
- 我實際跑過的結果，包括 9 個情境和 5 個 bug：`demo/DEMO-LOG.md`
- 各章重點：`book-summary.md`

**題庫**：第 5 章需要 `technician.csv`。直接從 `code/HAM-Radio-Practice-Web/data/technician.csv` 複製到練習資料夾，題庫不必讓 AI 生成，這和書上的做法一致。
