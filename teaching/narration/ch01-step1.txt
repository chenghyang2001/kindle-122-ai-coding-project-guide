歡迎來到 K122，讓 AI 寫出好程式，AI Coding 專案開發實戰指南的互動教學。
這本書和上一本 K120 最大的不同，是作者輪流用了六種 AI 工具，包括 GitHub Copilot、ChatGPT、Gemini、Blackbox AI、Tabnine 和 Cursor。
我們的做法是，全部用 Claude Code 來扮演這些工具的角色。因為這本書真正要教的，不是哪個按鈕在哪裡，而是每一個開發階段，要怎麼和 AI 協作。
第一章是觀念章，不寫程式。我們只做一個小實驗，驗證書上一點五節最重要的一句話：大型語言模型不是資料庫。
資料庫是查詢事實，查不到就說查不到。語言模型是預測下一段文字，所以就算答案不存在，它也可能編出一段看起來很合理的說明，這就是所謂的幻覺。
現在請打開另一個終端機，用 cmd 建立練習資料夾。輸入 mkdir 百分比 USERPROFILE 百分比 反斜線 workspace 反斜線 k122-ch01-practice，再 cd 進去，然後輸入 claude 啟動。
第一句提示詞，請你照說明檔原文貼上。內容是問它，requests 套件的 get json safe 函式怎麼用，請給一個範例。注意，這一句不要叫它執行任何東西。
看它怎麼回答。它是直接寫出一段範例，還是告訴你這個函式不存在？
接著貼第二句：請用 python 負 c 實際驗證這個函式存不存在，不要憑記憶回答。
最後再貼第三句：比較你第一次和第二次的回答，哪一次比較可信，為什麼。
這一步要觀察的重點有兩個。第一，只用說的時候，它有沒有編造。第二，讓它實際執行之後，答案有沒有改變。
這也呼應了書上的建議：AI 的輸出一定要驗證，而最好的驗證方式，就是讓工具實際跑一次。
